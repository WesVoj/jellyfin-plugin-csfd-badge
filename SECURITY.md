# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

Please use GitHub's private security advisory feature instead of opening a
public issue for vulnerabilities.

## Deployment guidance

- Keep `node-csfd-api` on a trusted private network.
- Do not forward its port on a router or expose it through a public reverse proxy.
- Only install release artifacts from this repository.
- Keep Jellyfin, JavaScript Injector, and File Transformation updated.
